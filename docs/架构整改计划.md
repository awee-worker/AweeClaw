## 二、P0 - 立即整改（安全/稳定性）

### P0-1: 收紧 CSP 安全策略
- **状态**: [x] 已完成
- **文件**: `src/main/appBootstrap.ts`
- **问题**: CSP 策略过于宽松，`script-src 'unsafe-inline' 'unsafe-eval'`、`connect-src 'self' https:`、`frame-src https:` 存在 XSS 和数据外泄风险
- **方案**:
  1. 移除 `unsafe-eval`（Monaco 硬性依赖，保留但添加注释）
  2. `frame-src` 限制为本地开发服务器
  3. 新增 `object-src 'none'`、`base-uri 'self'`、`form-action 'self'` 防御策略
- **影响范围**: 主进程 CSP 配置

### P0-2: API Key 加密存储
- **状态**: [x] 已完成
- **文件**: `src/main/modules/settings-db/SettingsDb.ts`、`src/main/guard/safeStorageUtil.ts`（新建）
- **问题**: API Key 明文存储在 SQLite 和 localStorage 中，renderer 进程可直接读取
- **方案**:
  1. 新建 `safeStorageUtil.ts`，封装 Electron safeStorage 加密/解密
  2. SettingsDb 写入时加密 API Key 和渠道凭证
  3. SettingsDb 读取时解密返回
  4. renderer 通过 IPC 获取解密后的值
- **影响范围**: 设置持久化层、IPC 通道

### P0-3: 清除 console.log 残留
- **状态**: [x] 已完成
- **文件**: 20+个业务文件
- **问题**: 生产环境日志泄露，应统一走 LogEngine
- **方案**:
  1. 全局替换 `console.log/warn/error` 为 `logger.xxx`（按模块分类）
  2. 保留进程级兜底（appBootstrap uncaught exception）和 Logger 自身 fallback
  3. 保留代码模板/片段中的 console（snippetAdapter、scenario-system/cli）
- **影响范围**: 全局业务代码

### P0-4: 修复空 catch 块
- **状态**: [x] 已完成
- **文件**: 20+个文件，包括 themeDefinition、toolExecutors、IntelligenceCore、languageServerManager、scenarioInstall、WeixinChannelPlugin、authSlice、backendApi 等
- **问题**: 多处 `catch {}` 静默吞没错误，影响问题排查
- **方案**: 补充 `logger.xxx.warn/error/debug` 记录异常信息，按模块分类
- **影响范围**: 全局错误处理
